# fjdesign.co

Personal portfolio of Fábio José — UX/UI & Web Designer, Creative Technologist & AI Builder.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Embla Carousel
- React Router v7
- Formspree (contact form)

## Features

- Dark / Light mode
- PT-BR / EN language toggle
- Case study pages
- AI Lab section
- Contact form with Formspree integration

## Getting Started

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
